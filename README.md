# MarkupCLI++
A C++ project that allows for easy creation of *Markdown files* using a CLI, for **Linux**, **Windows**, and **macOS**.

## Flags
```bash
--header
--text
--note
--important
--tip
--image
```

## How to build?
```bash
git clone https://github.com/Nahida4479/MarkupCLI.git
cd MarkupCLI
make
```
> Note: `make` builds a Linux binary only. For Windows and macOS, download a pre-built binary from [Releases](https://github.com/Nahida4479/MarkupCLI/releases).
